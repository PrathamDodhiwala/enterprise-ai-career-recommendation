# 🚀 Enterprise AI Career Recommendation System

An enterprise-level AI-powered career analytics and recommendation platform built using Machine Learning and Streamlit.

---

# 🚀 Features

- AI Career Recommendation Engine
- Skill Gap Analysis
- Salary Prediction System
- Resume Readiness Score
- AI Learning Roadmaps
- Interactive Analytics Dashboard
- KPI Monitoring
- Downloadable Reports
- CSV Upload Support
- Business Intelligence Visualizations

---

# 🛠 Tech Stack

- Python
- Streamlit
- Scikit-learn
- Plotly
- Pandas
- NumPy
- Joblib

---

# ⚙ Installation

```bash
pip install -r requirements.txt
python train_model.py
streamlit run app.py
```
